LiveABC｜HTTPS 讀取測試

這是 HTTPS 診斷測試頁（V3），使用已通過播放測試的音檔網址，不是字幕完成版。請在 iPad Chrome 打開，依序測試播放和跨網站讀取。

1. 選擇音軌

尚未載入

只針對你選取的一個音軌進行測試；不會批次下載音檔。

2. 播放測試

請先點「載入音軌」，再按播放器的播放鍵。

3. 跨網站讀取測試

點擊後，會向目前音軌請求少量音訊資料，檢查 Chrome 是否允許讀取；不會將音檔傳給其他服務。

尚未測試。

請確認本頁網址是 https:// 開頭；若是 file:// 開頭，結果不能用來判斷 HTTPS 網站是否有權限。

4. 下一階段

若播放與讀取都通過，再測試 iPad 的語音辨識模型、逐字稿時間戳與字幕同步。此頁不會擷取其他 Chrome 分頁的聲音。

如因出版商伺服器的權限政策而無法讀取，仍可考慮由使用者手動選擇合法取得的音檔。

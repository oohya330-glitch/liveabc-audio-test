# 英文精讀電子書 V2 固定母版

此資料夾保存已確認的 V2 電子書 HTML 設計與互動功能。

- 範本：`index.html`（示例文章，非正式書庫文章）
- 正式閱讀書庫：`../../library/`
- 新文章應建立在 `reading-notes/<english-slug>/index.html`，**不要覆寫此範本**。
- 依照範本修改：`<title>`、文章編號、英文／中文標題、句數、`const data`、全文主旨。
- `data` 每句包含 `en`（英文原文）、`zh`（繁體中文翻譯）、`words`（[字詞、語境字義、補充解析] 陣列）、`grammar`（文法與邏輯）。
- 保持原文無上色、無重點加粗；字詞按鈕與文法說明預設收合。
- 保留 25px 英文、A−／A+、翻譯顯示、純英文閱讀、深淺模式、閱讀設定。
- 新文章的「返回閱讀書庫」網址通常是 `../library/`（範本在子資料夾內，所以使用 `../../library/`）。
- 每新增一篇，更新 `reading-notes/library/index.html` 的文章卡片、搜尋字串與篇數。
- 完成後檢查 HTML 原文與翻譯句數、返回連結、書庫連結，並驗證 GitHub 檔案；公開 Pages 部署另行確認。

請勿修改已有文章的原文與解析，除非使用者要求。
